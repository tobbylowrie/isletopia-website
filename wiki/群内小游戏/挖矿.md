# 群内小游戏 · 挖矿

「一日矿洞」是一个**全服共享、回合制**的挖矿游戏：每天 08:00 后可下矿一次，从洞口 (0,0) 往下探索一座全服共同的矿洞。移动、开采、战斗都消耗**饱食度**，用完就会被困在洞里等人来救。矿洞里埋着矿脉、宝箱、幸运方块与怪物，矿脉周围有怪物看守；深处有下界传送门通往岩浆海与下界要塞，赛季主线则要从 8 条线索里找到要塞、献祭末影之眼打开末地门、屠龙拿到藏宝图，最后挖出**矿洞之心**。场外的装备升级线永不丢失——换赛季只是换一座新矿洞。

## 一、游玩流程总览

1. **前置条件**：完成 QQ 绑定（见[QQ 机器人绑定系统](../QQ群功能/QQ机器人绑定.md)）。指令**仅在 QQ 群可用**，赛季播报也发在群里。
2. **下矿**：每天 08:00 后发一次 `/挖矿 下矿`，从洞口 (0,0) 出发，自带 **10 点饱食度**。
3. **探索**：`/挖矿 左` `/挖矿 右` `/挖矿 下` 逐格移动（只能往下，不能往上）；`/挖矿 火把` 照亮周围（永久可见）；`/挖矿 开采` 挖矿脉、开宝箱、挖幸运方块；踏进怪物格会进入战斗。
4. **返程**：`/挖矿 返程` 任意位置爬出（-1 饱食度），矿袋里的矿物按售价**自动折算金币入账**，没花完的消耗品回到携带栏。
5. **被困**：饱食度耗尽会被冻结在原地，矿袋也冻在那里；等群友走到你那一格 `/挖矿 救援`，或者自己用末影珍珠逃生、`/挖矿 放弃`。
6. **场外养成**：返程前 `/挖矿 保留` 把材料存进仓库，再 `/挖矿 升级` 矿镐 / 护具 / 背包、`/挖矿 附魔`——装备与仓库**跨赛季永不丢失**。
7. **赛季主线**：线索、末影之眼、末地水晶、屠龙进度都是全服一起推；龙死次日 08:00 世界刷新，开启新赛季。

> 每个动作（移动 / 开采 / 攻击……）就是一回合，群消息里的 9×9 视口会随之刷新；视口下方的按钮和发指令等价，点一下就行动。

## 二、饱食度与每日循环

饱食度是唯一的行动资源：**每次下矿自带 10 点，上限 15**。

| 动作 | 消耗 |
|---|---|
| 踏入未探索格 | -1（已探索格免费通行） |
| 返程 | -1 |
| 开采普通岩层 | -1 |
| 开采深板岩（y≥29） | -2（先布置 TNT 可降到 -1） |
| 开采末地水晶 | -2 |
| 挖幸运方块 / 挖出矿洞之心 | -1 |
| 踏入空洞 / 流沙 | -1 |
| 站在毒气上（每个动作） | -1（牛奶本次免疫） |
| 下界高温（每个动作） | -1（火焰保护附魔免） |
| 中毒（洞穴蜘蛛，每回合） | -1（牛奶解） |
| 被监守者震回 | -2（羊毛垫或潜行附魔可安全通过） |
| 攻击 / 逃跑 / 插火把 / 使用道具 / 丢弃 / 保留 / 交易 | 免费 |
| 救援他人 | -1 |

- **食物**：面包 +1（30 金币）、牛排 +2（80 金币）、金苹果 +4 并挡下一次伤害（500 金币）；被尸壳咬到会「饥饿」，本次下矿食物回复减半。
- **岩浆**：踏入岩浆会烧掉矿袋随机 1 件物资，用水桶可永久扑灭；下界的岩浆海更凶，一次烧 2~3 件。
- **每日一次**：每天 08:00 重置下矿机会，一天只能下一次；被困状态跨日保留，救出来或放弃后才能再次下矿。

## 三、地图、深度与移动

- 矿洞**全服共享**：别人探索过的格子，你走上去免费（视口里会显示是谁先探到的）。
- 视口为 **9×9**，图例：⬛未探索 ▫️仅照亮 🟫石头 ⬜深板岩 💎矿物 ☠️怪物 🎁宝箱 🧰稀有箱 ❓幸运方块 🕳️洞口 🆘被困者 @你。
- 只能**左 / 右 / 下**移动，不能往上；返程随时可用。
- 主世界 x∈[-120, 120]，y∈[0, 64]（y61~64 是基岩带，走不过去）。深度分带：

| 深度 | 分带 | 主要产出 |
|---|---|---|
| y0 | 洞口 | 起点，无内容 |
| y1–12 | 浅层 | 煤、铜 |
| y13–28 | 中层 | 铁、青金石 |
| y29–48 | 深层 | 金、红石、钻石（深板岩开采 -2 饱食度） |
| y49–60 | 深渊 | 钻石富集、末影人、远古城市 |
| y61–64 | 基岩 | 不可通行 |

主世界还散布着**废弃矿井（刷怪笼房）、地下湖、紫水晶洞、远古城市、要塞入口与下界传送门**等结构。火把插在刷怪笼上可以**封印**它，否则第二天 08:00 怪物会重新出现。

## 四、火把与勘探熟练度

火把 10 金币一个，插下后**永久照亮**周围（幸运方块照不出来，只有踏进去才现形）。照亮格数会累计成**勘探熟练度**，档位越高，火把范围越大、看到的情报越细：

| 档位 | 累计照亮 | 火把范围 | 情报精度 |
|---|---|---|---|
| I | 0 | 上下左右 4 格 | 只看到「这里有矿 / 怪 / 箱」 |
| II | 60 | 周围 8 格 | 看清矿物种类 |
| III | 300 | 周围 8 格 | 看清怪物种类与数量 |
| IV | 1000 | 菱形 12 格 | 识破蠹鱼伪装、分辨宝箱品质 |
| V | 3000 | 菱形 16 格 | 标注陷阱（岩浆 / 空洞等）稳定性 |

- **矿工头盔**（稀有宝箱掉落）：火把范围 +1 档。
- **指南针**（200 金币）：本次下矿信息精度 +1 档，可与熟练度叠加。

- **守卫锁定**：矿脉 / 宝箱周围 **8 格**内有活怪时不能开采——先清怪；怪物格会锁定 5 分钟（战斗中别人进不来）。
- **宝箱**：普通箱约 50–150 金币等值物资；稀有箱约 300–800，25% 额外掉落探索道具；远古城市顶级箱约 800–1500，45% 掉落再生图腾 / 附魔卷轴。
- **蠹鱼**会伪装成矿脉，一镐下去才现形（IV 档熟练度可提前识破）。
- 矿袋容量 = **20 + 背包每级 1 格**（上限 50）；负重按上表累计，**穿戴中的装备也占负重**；超重时先 `/挖矿 丢弃 <物品>` 腾位置，或直接返程。
- 怪物掉落的资源道具同样能折算金币：腐肉 8、线 12、骨头 15、火药 25、绿宝石 33。
- **主线道具**：末影人掉落的**末影珍珠**、烈焰人掉落的**烈焰棒**不占矿袋、不折算金币、跨赛季保留，用于赛季主线的献祭（见第十一节）。

## 六、怪物与战斗

踏进怪物格（或挖开蠹鱼）即进入战斗：**攻击不耗饱食度**，但每次失手怪物都可能反击。

- **战力** = 镐子基础 + 每级 +1：木 12 / 石 20 / 铁 35 / 钻 55 / 合金 80（幸运方块「时来运转」+10）。
- **护甲值** = 护具基础 + 每级 +1 + 附魔：皮 4 / 锁链 7 / 铁 10 / 钻 18 / 合金 25（坚固 +5，其余附魔 +3）。
- **胜率** = 50% + 4% × (战力 − 怪物血量)，夹在 5%~95%；**击穿率** = 40% + 3% × (怪物攻击 − 护甲值)，夹在 5%~95%。两者每回合都会展示，方便你决定打还是跑。
- 胜利后怪物**永久清除**并掉落资源（同时解除守卫锁定）；失手被击穿则 -1 饱食度。
- **逃跑**撤到相邻已探索格（优先来路），不耗饱食度；骷髅会追一箭（必中），其他怪物 35% 追击。

## 八、被困与救援

- 饱食度归零会被**冻结在原地**：矿袋与带入物资锁在那一格，群里播报 🆘 喊人来救。
- **救援**：任意玩家在自己的下矿中走到被困者那一格，`/挖矿 救援`——救援者 -1 饱食度，被困者 +1 饱食度解脱，**矿袋物资全部保住**。
- **自救**：`/挖矿 使用 末影珍珠`（800 金币）立即返程并保留矿袋；`/挖矿 放弃` 当场解脱，但矿袋与带入物资全部清空。
- **再生图腾**（远古城市宝箱）：被困瞬间自动触发一次，+3 饱食度继续游戏。
- 被困状态跨日保留：当天被救出来就能继续玩，没人救就得等第二天。

## 十、三界与传送

矿洞不止主世界：**下界、要塞、末地**各自是一张独立子图，靠传送格连接。

| 地图 | 范围 | 内容 |
|---|---|---|
| 主世界 | x -120~120，y 0~64 | 全部矿物、怪物、宝箱、结构与赛季线索 |
| 下界 | x -80~80，y 0~32 | 石英 / 金 / 远古残骸、岩浆海、猪灵、烈焰人、下界要塞 |
| 要塞 | 40 × 20 迷宫 | 走廊房间迷宫、图书馆（第 8 条线索）、末地门 |
| 末地 | 41 × 41 | 主岛（末影龙 + 5 颗水晶）+ 外岛（潜影贝、稀有宝箱） |

- **下界传送门**（主世界 2 座，双向配对）：踩上去即传送；下界高温每动作 -1 饱食度，**火焰保护**可免。
- **猪灵**中立：`/挖矿 交易` 用 1 个金换 1~2 件物资（面包 / 火把 / 水桶 / 线 / 骨头 / 火药）；动手打过猪灵后，全下界的猪灵都会敌对。
- **要塞入口**藏在主世界深层，进去是走廊-房间迷宫；图书馆有第 8 条线索，出口在 (39,19)，末地门在传送门房间。
- **末地门**：集齐 **12 颗末影之眼**（见下节）后踏上门格进入末地；主岛中央的末影龙就是赛季 Boss。

## 十一、赛季主线（四幕）

赛季是全服一起推的一条主线：

**第一幕 · 拓荒**：主世界深部（y≥40）散布着 7 条线索，要塞图书馆里还有 1 条，共 **8 条**。发现线索会群内播报方位提示，线索越多、要塞位置收得越窄。

**第二幕 · 寻钥**：在要塞传送门房间 `/挖矿 献祭之眼`，每献祭一颗消耗 **1 末影珍珠 + 1 烈焰棒**（末影人 / 烈焰人掉落，不折算金币）。集齐 **12 颗**末地门开启；6/12 与 12/12 都会播报。

**第三幕 · 决战**：进入末地，先砸 **5 颗末地水晶**（每颗 -2 饱食度）降低难度，再攻击末影龙：

- 屠龙率 = (8% + 0.5% × (战力 − 60))，夹在 2%~60%；**每存活 1 颗水晶再 ×0.85**；
- 攻击不耗饱食度、不限次数；失手 30% 被龙息灼烧 -2 饱食度（火焰保护减免，金苹果护盾可挡）；
- 屠龙成功的**最后一击者**获得矿洞之心藏宝图（藏宝格在主世界深部，状态栏会显示方位）。
