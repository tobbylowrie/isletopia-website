# 2025.11.28 更新

1. 现在接收非系统邮件需要支付50金币，若金币不足，则物品无法到账。
2. 已优化邮件打开速度
3. 现在不再收取钓位费，而是在QQ群钓鱼和助力奖励减半，频道和网页不受此影响。
4. 现在助力会收取50金币费用。若钓鱼失败，助力者将损失50×鱼等级的金币
