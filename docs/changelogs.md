# 更新日志

## 2026.6.17

- 粘液的底层tick逻辑发生了改变，不是每10tick进行一次全局tick，而是每个区块独立进行tick，这会改善mspt与tps不一致问题。此次改动可能会对依赖时序的粘液机器产生影响，现在每个tick最多分配25ms用于粘液机器，如果超出25ms则会跳过tick。
- 现在QQ群钓鱼收竿区间长度进行了调整，会随机上下浮动50%，而不是固定值。

## 2026.6.7

1. 钓鱼系统已切换为 QBot 玩法（仅Q群可以玩），抛竿后不再主动推送上钩提醒。玩家需要通过查看状态或主动收竿来判断时机。
2. 每次钓鱼最多可以试探收竿 5 次。未上钩时会提示大致剩余时间，不会直接取消本次钓鱼。
3. 鱼上钩后会在 5-30 分钟内逃跑。鱼越高级窗口越短，高等级鱼竿可以显著延长收竿时间。
4. 新增今日鱼群倾向：莽撞、积极、适中、谨慎、胆小。收竿时机越符合今日倾向，奖励倍率越高（与暴击是乘积关系，现在最高10倍奖励）。
5. 暴击钓鱼改为首次收竿后揭示。玩家需要先收竿确认暴击，再让其他玩家助力，助力完成后再次收竿获得奖励。
6. 自动收竿在 QBot 版本中暂时关闭。新版钓鱼更强调玩家主动判断和协作。

## 2026.5.27

- 现在玩家配额200只实体跟踪，超过200后远处的怪物会减少发包次数（只影响视觉效果），越远减包的概率越高。（超过200后的起始减包距离是32格，随着追踪数量上升，距离会变近）

- 对一些内部架构进行了调整，优化了性能，预期无感知。

- 现在远处实体Pos、PosRot、Motion的包也受控
- 优化了货运网络的性能问题，并且增加了失败CD5秒。
- 修复了重启后机器人异常的问题
