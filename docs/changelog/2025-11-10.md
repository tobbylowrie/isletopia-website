# 2025.11.10 更新

1. 挖矿小游戏。玩家每日在群内发送"/挖矿"即可参与挖矿小游戏，每日最多一次，每次挖矿将提升镐子等级。镐子等级越高奖励越丰富，奖励将发往玩家邮箱。若长时间不挖，则镐子等级会下降，在镐子达到70级后有概率挖出海洋之心，等级越高概率越高。
2. 种菜小游戏。玩家一共有8个地皮，可以使用金币种植作物，若干小时后可收获作物，获得丰富奖励。每日可以偷别人菜一共4次。催熟作物4次。每日会有一个幸运作物，收获时有5%概率获得海洋之心奖励。详情"/农场 帮助"。

以上小游戏中的海洋之心目前仅发放实体物品，后续验证概率无误后更正为电子海洋之心。
