# 2024.10.17 更新

- **修改描述**：对部分neeko的技能描述做出了一些修改，描述更为准确易懂
- **羊neeko修复**：上线，切换neeko时不再刷新幸运色
- **悦灵neeko修复**：添加了部分可以旋转的方块（例如未伸出的活塞），旋转方块不再是随机方向
