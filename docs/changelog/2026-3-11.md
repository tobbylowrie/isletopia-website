# 2026.3.11 更新

1. 现在开始收10%税了，3月的税已收取，游戏输入/tax可以看到本月税额，金币购买海洋之心可以抵扣下个月税额。详见上一条公告（可以理解为每月必须花10%购买海子，不然就扣掉）。
2. 现在开始正常收电费了，机器人和游戏内都可以查账。
3. 修复了一些性能问题，现在云仓的自动补货、投掷器和漏斗直连云仓的功能暂时禁用，很快就会回来。
