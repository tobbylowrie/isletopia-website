# 2024.10.19 更新

- **勋章佩戴更新**：由于部分玩家拥有勋章过多，出现了显示错误，现在每个人只能展示5枚勋章，可以在游戏内使用指令/achievement display \[勋章名\]设置展示的勋章。如不设置则展示最近获得的5枚。
- **头颅展示幻形**：幻形列表中初始等级显示为泥土，1级及以上会使用生物对应的头颅显示，头颅数量对应等级。
- **tab列表修复**：可以正确的显示游戏内玩家数量，名字
- **添加兔子幻形**：（获取方式隐藏）持续提供跳跃提升2buff
- 使用幻形时起床不再使玩家掉线
