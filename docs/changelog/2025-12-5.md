# 2025.12.5 更新

1. 钓鱼小游戏上钩时间修改。
   - 未打窝：基础60-90分钟，每级增加5-15分钟，暴击倍率每倍增加15-30分钟。
   - 已打窝：基础30-90分钟，每级增加0-15分钟，暴击倍率每倍增加0-30分钟。
   - 打窝将已抛竿的钓鱼减少15分钟上钩时间。
2. 增加新的蚯蚓
   - 大蚯蚓 800金币 只能钓上3-9级以上的鱼.
   - 巨无霸蚯蚓 3000金币 只能钓上6-9级以上的鱼.
   - 普通蚯蚓 50金币 只能钓上1-6级鱼
3. 助力时间增加，每一人助力，增加30秒过期时间。
4. qq群彻底禁用，群小游戏请前往频道游玩。
5. 现在单方块不再需要放置一个方块挖掉，在无方块时会自动填充方块（水和空气都视为无方块）。
