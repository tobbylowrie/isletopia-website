# 2026.1.27 更新

1. 现在菜单不再根据上下级进行返回，而是实际浏览记录。
2. Dialog菜单覆盖了更多场景，现在指令默认使用Dialog新菜单，而不是箱子菜单。
3. 在菜单->辅助功能->功能选项中增加了"尽可能使用旧版菜单"的选项，提供给旧客户端玩家使用。
