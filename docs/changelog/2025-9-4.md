# 2025.9.4 更新

1. 钟表改为与旧版菜单绑定，新玩家不再发放钟表。旧版菜单将保持更新，后续视新玩家使用情况而定是否恢复使用旧版菜单。
2. 云仓改版V2，允许取出/存入任意物品，不再需要高级云仓，但上限设置为64组，不再允许转账。
   - 原有开启高级云仓的，每个物品栏补偿10000金币。
   - 现在可以取出整盒物品（/ci getBox xxx）。
   - 对于超出9999的物品将保留至2026年1月1日，请尽快取出，逾期超出部分将被删除。
   - 单堆叠物品允许放入云仓。
   - 现在，取出的烟花等特殊物品将与原版保持一致。
3. 不再允许普通玩家发送邮件。
4. 由于已开启死亡不掉落，暂时关闭垃圾桶功能，后续考虑彻底关闭。
5. 现在取消了"自动确认对话框"，不再允许自动确认，所有对话框都需要玩家手动确认。
6. 取消双维度传送门传送效率限制。
7. 小游戏奖励修改：第一名获得500*参加人数的金币。第二名及以后分别获得前一名的一半金币。
8. 悦灵修改：
   - 初始效果："死亡时不会掉落背包中的物品"改为"持续获得生命恢复I"
   - Lv5效果："能够使用服务器全局回收站和回收站查找功能。"改为"手持唱片右键可在原地播放音乐。"
