# 2025.11.4 更新

1. 小游戏的奖励进行调整，若同一名次中占有多个玩家，则将占有后续名次，并将这些奖励平分。例如第一名4人，第二名4人，则第一名的四个玩家均分1-4名的金币奖励，第二名的四个玩家均分5-8名的金币奖励。
2. 默认存档的岛屿不再允许使用超限附魔的物品，粘液空岛除外。
3. 关闭了反作弊。
